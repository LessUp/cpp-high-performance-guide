# [v1.0.1] - 2026-03-06

## Summary

GitBook integration, unit tests expansion, and cross-platform compatibility improvements.

## Added

### Documentation
- `CONTRIBUTING.zh.md` - Chinese contributing guide
- `.gitbook.yaml` - GitBook configuration with explicit readme/summary
- `SUMMARY.md` - GitBook table of contents
- `docs/en/gitbook-sync.md` - GitBook integration guide (English)
- `docs/zh/gitbook-sync.md` - GitBook integration guide (Chinese)

### Testing
- `tests/unit/modern_cpp/` directory with unit tests
- `tests/unit/modern_cpp/modern_cpp_examples_test.cpp` covering:
  - Compile-time factorial/hash/prime utilities
  - Move semantics behavior
  - `reserve()` allocation impact
  - Ranges vs loops consistency
- `HPC_TEST_MODE` macro for test-friendly code reuse

### CI/CD
- `tests/integration/build_system_test.py` enhancements:
  - Target-based CMake usage checks
  - Example module structure validation

## Changed

### CMake
- `examples/CMakeLists.txt` - Added per-module build switches
- `tests/unit/CMakeLists.txt` - Integrated modern_cpp unit tests

### Code Structure
- Property test files reorganized:
  - `main()` moved to end of files
  - Consistent entry point ordering

### README
- Enhanced badge styling (`for-the-badge` style)
- Added bilingual navigation links
- Added GitBook sync guide links

## Fixed

### Cross-Platform Compatibility
- `tests/property/benchmark_properties.cpp`:
  - Replaced hardcoded `/tmp/` with `std::filesystem::temp_directory_path()`
  - Added unified temporary file path generation

### Template Design
- SIMD dispatch template: changed single `Func&&` parameter to four separate template parameters (`ScalarFn`, `SseFn`, `AvxFn`, `Avx512Fn`)

### Windsurf Configuration
- MCP configuration standardized
- Automatic backup before changes

## Security Note

Recommended rotating exposed GitHub Personal Access Token after this release.
