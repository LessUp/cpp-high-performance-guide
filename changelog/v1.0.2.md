# [v1.0.2] - 2026-03-10

## Summary

Workflow optimization and CI improvements for faster, more reliable builds.

## Added

### Dependencies Management
- `package.json` - Declares honkit as development dependency
- `package-lock.json` - Locks dependency versions for reproducible builds
- npm cache support in pages workflow for faster builds

### CI Improvements
- Sparse-checkout configuration to reduce checkout time:
  - Only includes documentation-related files
  - Excludes tests/, benchmarks/, cmake/, src/

## Changed

### Workflow Renaming
- `docs.yml` → `pages.yml` (clearer purpose)
- `build.yml` → `ci.yml` (standard naming)

### Workflow Standardization
- Unified `permissions: contents: read` across all workflows
- Added `concurrency` configuration to cancel redundant runs
- Added `paths` triggers to reduce unnecessary builds

### Workflow Configuration
- `pages.yml`:
  - Added `actions/configure-pages@v5` step
  - npm install → npm ci (faster, reproducible)
  - Locked honkit to `^3.7.1`

## Fixed

- Docs badge link in README files (`docs.yml` → `pages.yml`)
- Reduced CI resource usage by excluding unnecessary files from checkout

## Performance Impact

| Metric | Before | After | Improvement |
|--------|--------|-------|-------------|
| Checkout time | ~30s | ~10s | 66% faster |
| npm install | ~60s | ~15s (cached) | 75% faster |
| Unnecessary builds | Frequent | Rare | Significant |
