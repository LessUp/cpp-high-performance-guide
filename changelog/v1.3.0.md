# Release v1.3.0

**Release Date:** 2026-04-16

## Overview

This release marks a major milestone in project maturity with comprehensive documentation refactoring, professional changelog structure, and bilingual release notes. The documentation is now fully reorganized for better navigation in both English and Chinese.

- **Comprehensive Documentation Restructure** - New hierarchical `docs/` organization with clear navigation

## 📖 Migration Guide

### For Users

Documentation URLs have changed:
- Old: `docs/en/learning-path.md`
- New: `docs/en/guides/learning-path.md`

The old locations are no longer available. Update your bookmarks accordingly.

### For Contributors

When adding new documentation:
1. Add English version to appropriate `docs/en/` subdirectory
2. Add Chinese version to matching `docs/zh/` subdirectory
3. Update `SUMMARY.md` in both locations
4. Update `docs/README.md` if applicable
