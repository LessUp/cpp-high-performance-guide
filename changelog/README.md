## 📊 Versioning Scheme

We use [Semantic Versioning](https://semver.org/):

- **MAJOR** (X.0.0): Incompatible API or build system changes
- **MINOR** (0.X.0): New features, backwards compatible
- **PATCH** (0.0.X): Bug fixes, backwards compatible
