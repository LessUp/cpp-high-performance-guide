# [v0.1.0] - 2026-01-09

## Summary

Initial release of C++ High Performance Computing Optimization Guide.

## Added

### Project Structure
- Modern CMake build system with presets
- 5 example modules:
  - `01-cmake-modern/` - CMake best practices
  - `02-memory-cache/` - Memory and cache optimization
  - `03-modern-cpp/` - Modern C++ performance features
  - `04-simd-vectorization/` - SIMD and vectorization
  - `05-concurrency/` - Concurrency programming

### Dependencies (FetchContent)
- Google Benchmark v1.8.3 - Performance benchmarking
- Google Test v1.14.0 - Unit testing framework
- RapidCheck - Property-based testing

### Build Configurations
- CMake presets:
  - `debug` - Debug build
  - `release` - Release build with -O3 -march=native
  - `relwithdebinfo` - Release with debug info
  - `asan` - AddressSanitizer build
  - `tsan` - ThreadSanitizer build
  - `ubsan` - UndefinedBehaviorSanitizer build
  - `coverage` - Code coverage build

### CI/CD
- `.github/workflows/ci.yml` - Build and test
- `.github/workflows/benchmark.yml` - Performance benchmarks
- `.github/workflows/sanitizers.yml` - Sanitizer tests
- `.github/workflows/pages.yml` - Documentation deployment

### Example Content
Each module includes:
- Source files with optimization examples
- Benchmark files with Google Benchmark
- CMakeLists.txt with proper configuration
- README.md with module documentation

## Fixed

### Compilation Issues
- `tests/property/simd_properties.cpp`:
  - Added missing headers (`<algorithm>`, `<benchmark/benchmark.h>`, `<chrono>`, `<iostream>`, `<random>`)
  - Fixed `SIMDLevel::None` → `SIMDLevel::Scalar`
  - Fixed RapidCheck generator usage

### Benchmark Output
- `benchmarks/common/benchmark_utils.hpp`: Empty result now outputs `"benchmarks": []` for valid JSON

### Test Stability
- `tests/property/memory_properties.cpp`:
  - `SOAPerformanceAdvantage` defaults to correctness check only
  - Performance assertions require `HPC_RUN_PERF_TESTS=1` environment variable
  - Prevents random failures in CI/Debug environments
