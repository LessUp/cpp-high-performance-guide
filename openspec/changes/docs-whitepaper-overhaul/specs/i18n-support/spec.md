# Internationalization Support

## ADDED Requirements

### Requirement: Bilingual Whitepaper Surfaces

THE Documentation SHALL keep the primary whitepaper and academy surfaces available in both English and Chinese.

#### Scenario: Reader chooses either language

- **WHEN** a reader enters the docs site from the English or Chinese entry path
- **THEN** they can reach equivalent landing, academy, architecture, playbook, research, and contributing pages in
  their chosen language

---

### Requirement: Explicit Scope for English-Only Technical Detail

THE Documentation SHALL document which deep technical sections remain English-only by design after the redesign.

#### Scenario: Contributor evaluates translation work

- **WHEN** a contributor checks whether a new docs page requires a Chinese counterpart
- **THEN** the translation scope guidance clearly distinguishes bilingual whitepaper surfaces from English-only
  exercises or code-heavy API details
