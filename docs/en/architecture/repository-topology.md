# Repository Topology

This page is a stub map of the major repository surfaces that matter to readers and maintainers.

## Top-level surfaces

| Path | Role |
| --- | --- |
| `include/` | Header-only library surfaces and reusable performance utilities |
| `examples/` | Runnable teaching material tied to the learning modules |
| `benchmarks/` | Measurement-oriented executables used to verify performance claims |
| `tests/` | Unit and validation coverage |
| `docs/` | VitePress whitepaper, bilingual landing pages, and reference surfaces |
| `openspec/` | Change intent, requirements, and archive-ready decision records |
