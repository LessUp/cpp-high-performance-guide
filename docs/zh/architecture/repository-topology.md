# 仓库拓扑

本页是一个占位式地图，用于标记对读者和维护者最重要的仓库表面。

## 顶层区域

| 路径 | 作用 |
| --- | --- |
| `include/` | 头文件库表面与可复用的性能工具 |
| `examples/` | 与学习模块绑定的可运行教学材料 |
| `benchmarks/` | 用于验证性能结论的测量型可执行文件 |
| `tests/` | 单元测试与验证覆盖 |
| `docs/` | VitePress 白皮书、双语入口页与参考资料 |
| `openspec/` | 变更意图、需求与可归档的决策记录 |
