# AI 辅助开发流程

本仓库采用简化的 AI 开发流程，使用单一说明文件。

## 权威说明文件

- `CLAUDE.md` —— Claude Code 说明（权威 AI 指导文件）

如果文档与代码之间出现漂移，优先修正漂移，而不是绕过问题。

## 推荐流程

1. 保持文档与代码同步。
2. 使用仓库已有的 preset 驱动验证命令。
3. 在合并前或一个较大的清理阶段结束后使用 `/review`。

## 工具选择

- **LSP**：`clangd`
- **构建 / 测试入口**：`cmake --preset=...` 与 `ctest --preset=...`
- **hooks**：仓库自带 `.githooks/`
- **autopilot 策略**：优先更长的单次会话，只有在任务天然并行时才考虑 `/fleet`
